# Cyber Red Localhost Terminal

A glowing vibrant **red cyber-themed** local web app for easy localhost development.

## Features
- Displays your localhost address clearly
- Built-in web terminal to run shell commands
- Run Python, Java, HTML/CSS previews, and more
- Dark cyber aesthetic with neon red glows and scanlines
- **PWA support** – installable on Android like a real app
- Super simple to start

## Quick Start (Desktop)

```bash
pip install -r requirements.txt
python app.py
```

Then open the URL shown (usually `http://127.0.0.1:5000`).

## Install on Android (easiest way)

1. Start the app on your computer (`python app.py`)
2. Make sure your phone is on the same Wi-Fi
3. On your phone open Chrome and go to `http://YOUR-COMPUTER-IP:5000`
4. Tap the menu (⋮) → **Install app** or **Add to Home screen**

You now have a Cyber Red icon on your home screen.

## Notes
- This runs **locally only**. Commands execute on the machine running the Python server.
- Do **not** expose this to the public internet.
- Full interactive TTY terminal inside a pure APK is limited on Android without root.
