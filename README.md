# Cyber Red Localhost Terminal

A glowing vibrant **red cyber-themed** local web app for easy localhost development.

## Features
- Displays your localhost address clearly
- Built-in web terminal to run shell commands
- Run Python, Java, HTML/CSS previews, and more
- Dark cyber aesthetic with neon red glows and scanlines
- **PWA support** – installable on Android like a real app
- Super simple to start (almost no terminal needed)

## Easiest Way to Start (almost no terminal)

### Windows
1. Double-click **`start.bat`**
2. A browser window will open automatically
3. Done. Keep the black window open while you use the app.

### Mac / Linux
1. Double-click **`start.sh`** (or right-click → Run)
   - If it doesn’t run, open a terminal once and type:
     ```bash
     chmod +x start.sh
     ./start.sh
     ```
2. Browser opens automatically.

That’s it. You barely have to touch the terminal after the first time.

## Manual Start (if you prefer)
```bash
pip install -r requirements.txt
python app.py
```

## Install on Android
1. Start the app on your computer with `start.bat` or `start.sh`
2. On your phone (same Wi-Fi) open Chrome and go to the Network address shown
3. Tap ⋮ → **Install app** / **Add to Home screen**
