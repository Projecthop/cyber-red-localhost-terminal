# Cyber Red Localhost Terminal

A glowing vibrant **red cyber-themed** local web app for easy localhost development.

## Features
- Displays your localhost address clearly
- Built-in web terminal to run shell commands
- Run Python, Java, HTML/CSS previews, and more
- Dark cyber aesthetic with neon red glows and scanlines
- Super simple to start

## Quick Start

```bash
pip install -r requirements.txt
python app.py
```

Then open the URL shown in the terminal (usually `http://127.0.0.1:5000`).

## Requirements
- Python 3.8+
- Flask

## Notes
- This runs **locally only**. Commands execute on your machine.
- Use responsibly. Do not expose this to the public internet.
- For full interactive terminal (TTY), consider tools like `ttyd` or Termux on mobile.
